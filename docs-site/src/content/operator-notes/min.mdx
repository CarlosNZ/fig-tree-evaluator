Here, both read a whole list of prices from the data:

<Expression
  title="The cheapest and dearest prices in a list"
  code={`
    {
      cheapest: { $min: '$data.prices' },
      dearest: { $max: '$data.prices' },
    }
  `}
  data={`
    {
      prices: [12.5, 8, 4.25],
    }
  `}
/>

Strings are compared character by character, by their [Unicode code points](https://developer.mozilla.org/en-US/docs/Glossary/Code_point). That puts capitals before lower-case letters, and accented letters after both, so `{ $min: ['banana', 'Apple'] }` returns `'Apple'`. It also means numbers stored as text compare as text, so `{ $min: ['10', '9'] }` returns `'10'` — [`convert`](#op-convert) them to numbers first.
