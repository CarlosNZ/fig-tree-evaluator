The values must be all numbers or all strings. Give `values` a whole array from your data to find the smallest in it:

<Expression
  title="The cheapest and dearest prices in a list"
  code={`
    {
      cheapest: { $min: '$data.prices' },
      dearest: { $max: '$data.prices' },
    }
  `}
  data={`
    {
      prices: [12.5, 8, 4.25],
    }
  `}
/>

Strings are compared character by character, by their Unicode code points. That puts capitals before lower-case letters, and accented letters after both, so `{ $min: ['banana', 'Apple'] }` returns `'Apple'`. It also means numbers stored as text compare as text, so `{ $min: ['10', '9'] }` returns `'10'`. [`convert`](#op-convert) them to numbers first.
