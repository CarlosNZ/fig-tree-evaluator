Because only the chosen branch is evaluated, the other can safely hold something that would fail:

<Expression
  title="The branch not taken never runs"
  editor={false}
  code={`
    {
      $if: {
        condition: false,
        then: { $divide: [1, 0] },
        else: 'safe',
      },
    }
  `}
/>
