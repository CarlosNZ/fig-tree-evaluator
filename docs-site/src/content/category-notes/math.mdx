- **No conversion from text:** a number stored as text, such as `'5'`, is an error rather than converted, so [`convert`](#op-convert) it first. `plus`, `min` and `max` take text, but treat it as text: `{ $plus: ['5', '5'] }` returns `'55'`.
- **Finite results:** a result that would be `NaN`, `Infinity` or `-Infinity` fails instead, with the code `non-finite-result`, as when dividing by zero.
- **Floating point:** FigTree's arithmetic uses binary floating-point numbers, so a result can be a tiny bit off, as with `{ $plus: [0.1, 0.2] }`, which returns `0.30000000000000004`. [Round](#op-round) a result before showing it, especially an amount of money.
