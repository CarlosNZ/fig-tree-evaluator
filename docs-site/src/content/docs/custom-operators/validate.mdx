## The `validate` hook

A function over the parameter values known when the expression is compiled: each literal written on the node, and for a parameter left unset, its default, from the instance's `operatorDefaults` or the definition. Its third argument, `authored`, names the parameters the node writes, for a check about what the author wrote rather than what the operator will get.

## Findings

Reporting a problem as a finding, with its severity and parameter.

## Helpers

The toolbox the hook receives.

## When it runs

At `validate()`, `compile()` and the first `evaluate()` of an expression. A value only known at runtime, such as a `$data` reference, isn't passed to the hook.

## Declaring what it returns

`returns`, and the check it drives: a node whose declared result can't fit the parameter it feeds is an error when the expression is compiled. `returns` never includes `null`, and the engine never checks a body's result against it.
