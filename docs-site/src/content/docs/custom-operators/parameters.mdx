## Declaring parameters

Names, `required` and `default`, including `default: EvaluationData`, which gives the body the evaluation's data when the parameter isn't supplied. `truthiness`, which hands the body a boolean judged the way the core operators judge it.

The type vocabulary, literal types, and the constraints an array parameter can add.

## Null policy

What happens when a parameter is `null`: propagate it as the result, or pass it to the body. The conditional form. `elementNullPolicy`, the policy for each element of an array or value of an object, and `replacesNullAt`, a parameter whose value replaces a `null` at another.
