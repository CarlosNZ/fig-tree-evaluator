## What an expression is

Any JSON value. Operator nodes inside it are evaluated in place; everything else passes through untouched.

## Nodes and operators

A node is an operator plus its parameters. The `$`-prefixed key that invokes an operator, and what an operator is.

## Parameters

A parameter can be a plain value or another node, nested as deep as needed.

## The tree

Each node's result becomes a parameter of the node above it, and the result at the top is what's returned. The expression tree diagram goes here.
