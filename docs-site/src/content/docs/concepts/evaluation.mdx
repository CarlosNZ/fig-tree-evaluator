## Recursive and asynchronous

Children are evaluated before their parent, and evaluation is always async.

## Parameters an operator evaluates itself

Branching operators such as `if` evaluate only the branch they take.

## Types and nulls

The engine checks each parameter's type before the operator runs, and applies the operator's null policy.

## When evaluation fails

Errors stop evaluation unless a fallback catches them. A short summary, linking to the fallbacks and errors guide.
