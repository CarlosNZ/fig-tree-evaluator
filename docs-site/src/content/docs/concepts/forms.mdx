## Shorthand

`{ $plus: [1, 2, 3] }`: the form for writing by hand.

## Canonical

`{ operator: 'plus', values: [1, 2, 3] }`: every parameter named, the form tools and editors work with.

## Mixing the two

Both forms can appear in one expression, at any depth.

## Converting

Converting between the forms with `./format`, linking to the Tooling section.
