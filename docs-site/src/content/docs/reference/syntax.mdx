## References

Each reference name and its short form, what it reads, and the rule for when a `$` string is a reference rather than text.

## Nodes

What makes an object a node: an operator key, a fragment key or a single shorthand key, and what makes it plain data instead, including `literal`.

## Reserved keys

The keys that mean something on any node, such as `fallback`, `vars` and `noCache`, each in one line.

## Shorthand

The shapes a shorthand payload can take (named, positional, a single argument, a fragment's arguments) and the symbolic aliases.

## Null or failure

A table of what to reach for: a bare reference, `firstNonNull`, `get` with a default, `fallback`, operator defaults, `validate()`, and what each one responds to.

## A whole config

One complete config followed from authoring to a hostile run: checked before any data exists, run against data that breaks one field, then given a fallback per field so it survives that field and a timeout, with `fallbackCoverage` confirming it.
