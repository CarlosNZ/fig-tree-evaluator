## Introspection on the instance

`getOperators()` and `getFragments()`, which need no subpath. Most tools want `getCatalog()` instead, which joins these with the listings and fills the gaps, so this section says when the raw snapshots are the right choice and points to The catalog otherwise. `getDependencies()` and `isEvaluable()` are covered in Checking expressions and `inspect()` in Tracing and debugging, so this section links to them rather than repeating them.
