## Validating before you store

`validate()` reports issues without evaluating anything: unknown operators, malformed nodes, literal parameters of the wrong type.

## Issues

An issue's shape: its severity, code, message and path to the node.

## What an expression reads

`getDependencies()`: the data paths, fragment parameters and other references an expression uses, and when that set can't be known statically.

## Is there anything to evaluate?

`isEvaluable()`: whether a value holds anything for FigTree to do, such as a config object that may or may not contain operator nodes.
