## What it is

`fig-tree-editor-react`: a React component for editing FigTree expressions as a tree, for apps whose configuration authors write expressions. A live instance, which is also what the Playground is built with.

## Installing and a minimal setup

Installing the package, and the smallest working editor: a FigTree instance and an expression.

## Fitting it to your app

Operators and their listings through `getCatalog()` (linking to The catalog), fragments and the fragment editor, and theming.
