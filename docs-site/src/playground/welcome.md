# Welcome to the FigTree Playground

This is the place to try **FigTree** expressions in your browser. You can edit the expression and the data it reads, node by node in the tree or a whole object at a time as JSON5 text. Each example comes with notes like these, under **Info**, and there are more examples in the menu at the bottom of the page.

The tree editor is [fig-tree-editor-react](/editor/), a React component you can use in your own app.
