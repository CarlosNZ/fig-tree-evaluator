# Artifacts

Supplementary documents published as Claude artifacts — pages that live on claude.ai rather than in the repo, because they're presentation rather than specification. This file is the repo's record of what exists and where.

Each entry carries two links. The **artifact** link is the page as published on claude.ai, and it resolves for its owner and for members of the organization only: public links and email invites to people outside the organization are both turned off by the org's admin, so a `?sk=` share key does not make one readable by anyone else. The **rendered** link serves the committed copy in [../docs-artifacts/](../docs-artifacts/) through githack, which re-serves a raw GitHub file as `text/html` where `raw.githubusercontent.com` deliberately sends `text/plain` with `nosniff` — so a rendered link is public, because the repository is, and needs no GitHub Pages site.

Rendered links point at `main` and resolve once the v3 work merges there; until then, substitute the branch that holds the files (`V3-phase7-remaining-core`) for `main` in the URL. For a link that must never move, pin a commit SHA in place of the branch and use `rawcdn.githack.com`, which is githack's permanently-cached host — `raw.githack.com` is rate-limited and meant for development.
