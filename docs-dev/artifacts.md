# Artifacts

Supplementary documents published as Claude artifacts — pages that live on claude.ai rather than in the repo, because they're presentation rather than specification. This file is the repo's record of what exists and where.

Links are the **shared** form (with the `?sk=…` key): a bare artifact URL resolves only for its owner, so it's useless to anyone else reading this file. Share from the artifact page's share menu to get one.

- [FigTree v3 by Example](https://claude.ai/artifact/69z5N3h1r3UKbqQQZesAQC?sk=FL4gCRl5_1IMkNy4k3bqSQ) — nine walk-through v3 expressions, each a step harder than the last, from a single `$data` reference to a whole dashboard config with report mode and timeout shielding. Companion to the specs in [v3-specs/](v3-specs/). *2026-09-17*
- [FigTree From First Principles](https://claude.ai/artifact/Mu8ESY7vqhtZVkQvDQdXnG?sk=Wujwr3OF8ZwZUYaIl9pwqQ) — the whole v3 model derived forwards in fourteen stages, each mechanism justified by the problem that forces it, in plain language with the spec vocabulary introduced as it arrives. The on-ramp the fifteen spec docs don't provide. *(bare link — needs replacing with its `?sk=` share form)* *2026-09-17*
- [FigTree v3 Operators](https://claude.ai/artifact/KEw7w1N3gvLGXpSaUjMGwy) — every operator as a header over its parameters: the shorthand call shape, each parameter with its type, default and delivery mode, and what the node returns — filterable by name, alias, parameter or group. Built from the repo by `pnpm generate:operators`, which reads the registered definitions themselves, so it is **generated locally** into [docs-artifacts/](../docs-artifacts/) rather than downloaded, and republished from that file after each phase that lands operators. Supersedes the operator table formerly at `v3-specs/v3-operator-signatures.md`. *(bare link — needs replacing with its `?sk=` share form)* *2026-09-18*
